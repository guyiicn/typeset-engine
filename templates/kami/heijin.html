核心命题

"AI 的进步不来自单个模型，而来自持续改进当前模型的能力。" 报告把研发抽象成一台可重复运行的"爬山机"：数据管线、训练基础设施、RL 环境与奖励、评估套件、安全测试整体构成一个对指定领域做经验优化的闭环。

三条设计原则
  • 能力要"学到"而非"继承"——拒绝蒸馏，因蒸来的智能缺乏可控性与鲁棒性
  • 简单即可持续——简单可扩展的配方、干净可信的数据、透明的基础设施
  • 科学严谨不走捷径——一切决策须经 ladder / ablation / eval 验证
成绩定位（诚实）
  • AIME 2025 97.0 · AIME 2026 94.5
  • LiveCodeBench v6 87.7 · SWE-Bench Pro 52.8
  • 整体"对标 Sonnet 4.6，不领跑但全面稳健"
02

注意力模块

两条主线都用"交替"结构，并与 GPU 基础设施协同设计。以下是全篇围绕 attention 的几处关键设计。

注意力主结构 periodic local + global

5 层 local 配 1 层 global（5:1），抄 Gemma 3 思路，大幅压低训练注意力开销与推理 KV cache。local 用滑窗 512 + RoPE（base 10000）；global 层不用任何位置编码（NoPE），效果相当但更省。GQA：8 个 KV head，head dim 128，对 Q/K 加 RMSNorm，从而可用 FlashAttention-4 + Ulysses context parallelism。

attention 零初始化
  • 把 output RMSNorm gain 设 0。否则随机初始化时 softmax≈均匀=因果均值池化，使 token 表示趋同、MoE 路由严重失衡（越深越糟）
  • 开局像纯 FFN，cross-token 交互逐渐"长出来"
混合精度
  • 前向 GEMM FP8 E4M3，data-grad FP8 E5M2，weight-grad BF16+FP32 累加
  • 残差流 / router / embedding / 最终 logits 全 FP32；下转用 stochastic rounding
RL 中的注意力裁剪 · 基于 GRPO 的两处关键改动

① 自适应熵控制：用积分控制器在线调上裁剪界 k（目标熵 H*=0.3）——熵低放宽、熵高收紧，比显式熵 bonus 更好，免去手调。
② 外层 ratio clip：对所有分支加硬外裁剪（rmax=50, rmin 不约束），解决 GRPO 两个未裁剪分支偶发的梯度爆炸。

RL 爬山 · 从零学推理 teacher pipeline

起点是无任何推理痕迹的 checkpoint，从头学。先训三个专才，再 SFT 蒸成单一模型，最后轻量 RL 收尾：

Mid-trained→ STEM Teacher→ Agentic Teacher→ Help & Safety Teacher→ Trace Distill SFT→ Final RL · MAI-Thinking-1

RL 基础设施 · ROCKET

异步分布式：YOLO 当 learner、SGLang 当推理。最大 job 用 4864 颗 GB300，推理:学习 ≈ 4096:768（5.3:1）。核心是控制 learner 与 inference 引擎的数值差——两边都用 BF16 + MoE routing replay + top-p mask replay。多轮负载 prefix cache 命中率 97–98%。

防 reward hacking anti-cheat funnel 的另一面
  • 断网防搜 PR 答案、"时间旅行"清掉 base commit 之后 git 历史
  • grade 前重置被改测试文件、LLM 监控 monkey-patch 类作弊
  • 工具极简：仅 bash + string-replace，Terminal-Bench 成绩是泛化而非直训
04

给你的提示

1
把 EGFLOPs vs EGTime 的分离搬进任何架构选型决策。
很多"新架构不如老架构"其实是实现优化差距，而非架构本身——决策前先问"两边实现成熟度是否对等"。
2
rank invariance 不成立，是全篇最实用的警告。
小模型上的数据/配比结论别直接外推到大模型；多样性不足的高质量数据在大尺度会反噬。
3
"确定性换效率"是个明确取舍信号。
MFU 仅 ~20%、主动关 SHARP，说明 frontier 规模下"可复现 / 可调试"的价值高于峰值利用率。
