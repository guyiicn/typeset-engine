## 1. Distill 原料 → 结构化内容

### 何时触发

用户输入出现以下特征之一：

- 超过 200 字的连续自然语言（会议记录、脑暴）
- 散点式列表没有章节归类（"项目 1... 指标 X... 风险 Y..."）
- 聊天/邮件粘贴（有时间戳、"我觉得..."、"你说的..."）
- "帮我整理下这堆东西" / "把这些排一下"

### 流程

**Phase 1 · 提取（Extract）**

把所有**事实性原子**拎出来，忽略连接词和情感描述：

- 数字（金额、百分比、数量、日期）
- 专有名词（人名、公司、产品、地点）
- 动作项（"下周推"、"Q3 上线"）
- 引用（"XX 说..."）
- 因果关系（"因为 A 所以 B"）

输出形式：一个平铺的条目清单，不归类。

**Phase 2 · 归类（Classify）**

按目标文档的 section type 映射：

| 原子类型 | 常映射到 section |
|---|---|
| 量化指标（¥、%、人数、时长） | `kpi` 的 `metrics` |
| 对比数据（按时间/类别） | `chart`（bar/line/pie） |
| 观点/结论 | `quote` 或 `paragraph` |
| 清单项（3 项以上同质） | `table` |
| 事件时间线 | `table` 或独立 `heading` + `paragraph` |
| 二元决策（利/弊、机会/风险） | 两个 `heading` 并列 |

**Phase 3 · Gap-check**

做一个 3 列表格，和用户对齐：

| 模板需要 | 已从原料拿到 | 缺 |
|---|---|---|
| 4 个 KPI 卡 | 2 个（"ARR 1200 万"、"团队 30 人"） | 再 2 个量化 |
| 3 张图表 | 1 张（月度营收趋势） | 渠道分布、成本结构 |
| 执行摘要（200 字） | 无 | 需用户或 agent 起草（要声明） |
| 免责声明 | 无 | 用户提供或用默认 |

**Phase 4 · 问一次**

把 gap 表交回用户。**不要自作主张填空**。没有原料支撑的数字/结论一律不编造。

问句模板：

> "我从你给的内容里提取到 [N 条] 事实（附清单）。要用 [模板类型] 排版的话还缺以下 [M 项]：[表格]。请补充，或者确认哪些可以省略／用占位符。"

### 真实示例

**用户输入**：

> 昨天和客户开了个会，聊 Q2 的推广。他们觉得效果不错，上季度 ROI 大概 1:3，比 Q1 的 1:2 好。预算建议加 30%。不过他们担心信息流渠道饱和了，想试试中腰部 KOL 合作。团队这边小王负责执行，我 review。

**Phase 1 提取**：
- 时间：Q2 推广 / Q1 推广 / "昨天"（会议）
- 数字：ROI 1:3（Q2）、1:2（Q1）、+30% 预算
- 主体：客户、小王、"我"
- 担忧：信息流渠道饱和
- 动作：试中腰部 KOL、预算 +30%、小王执行我 review

**Phase 2 归类**（目标：一页纸复盘）：
- `kpi`: ROI 1:3 vs 1:2、预算增幅 +30%
- `paragraph`: 结论（效果好、继续投）
- `heading 风险`: 信息流饱和
- `heading 行动`: KOL 合作试点、执行分工

**Phase 3 Gap-check**：

| 模板需要 | 有 | 缺 |
|---|---|---|
| 标题 + 日期 | 日期（"昨天" → 今天？需确认） | 标题 |
| 3-4 个 KPI | 2 个 | 再 1-2 个（GMV？转化率？） |
| 时间线 / 里程碑 | 无 | KOL 试点的时间表 |

**Phase 4 问回**："以上是从你的描述里提取的。还缺 (a) 报告标题 (b) 1-2 个其他 KPI (c) KOL 试点时间表。要我用占位符先出一版让你补吗？"

## 2. 完整验证流程（Step 5 展开）

### 2.1 文件完整性

```bash
ls -la /tmp/report.pdf
# 期望大小 >50KB（空 PDF 只有 ~10KB）
```

### 2.2 页数

```bash
python3 -c "from pypdf import PdfReader; r = PdfReader('/tmp/report.pdf'); print(f'{len(r.pages)} pages')"
```

硬约束：

| 文档类型 | 页数约束 |
|---|---|
| resume | ≤ 2（严格）|
| one-pager | = 1（严格）|
| letter | = 1（严格）|
| long-doc / 白皮书 | 7±2（软） |
| portfolio | 6±2（软）|
| 投研报告（cicc/ms/cms/dachen） | 12±5（软） |

### 2.3 视觉抽查清单

用 `pdftoppm` 或在 macOS Preview 里扫一遍，检查：

- [ ] 字体渲染无 fallback（没出现"口"字或竖向日文平假名）
- [ ] 表格不溢出页面右边界
- [ ] 图表颜色和正文主题一致（不是 matplotlib 默认蓝橙绿）
- [ ] Tag / Badge 没有双层矩形（违反约束 7）
- [ ] 标题字体和正文字体 weight 相同（违反约束 4 会看到标题变粗）
- [ ] 页眉页脚对齐（cicc 风的红线不歪）

### 2.4 CSS 扫描（如果改了模板）

```bash
cd /home/guyii/clawd/code/typeset-engine
python3 scripts/validate_kami.py  # 如果已实现
# 或手工 grep
grep -rE "rgba\(|#(8c|99|a0|66|33)" templates/ styles/
grep -rE "line-height:\s*(1\.[6-9]|[2-9])" templates/
```

## 3. 反馈协议完整矩阵

用户说模糊话时的封闭式回问表。**永远先给当前值 + 2 个具体选项**，不要开放式问"你想怎么改"。

### 3.1 空间感

| 用户说 | 先查 | 回问模板 |
|---|---|---|
| 太挤了 / 压抑 | line-height、padding、letter-spacing | "X 的 line-height 现在 1.35。改成 (a) 1.5 让行距更透气 还是 (b) 把 padding 从 8mm 加到 12mm 让盒子外松一圈？" |
| 太松了 / 水 | 同上反向 | "X 的 line-height 现在 1.55。改成 (a) 1.4 密一点 还是 (b) 把段间距从 12mm 减到 8mm？" |
| 太空 / 稀薄 | 文字字号、section 数量 | "当前页占比约 60%。加 (a) 一个 KPI 区段 还是 (b) 放大正文字号从 10.5pt 到 11.5pt？" |

### 3.2 颜色

| 用户说 | 先查 | 回问模板 |
|---|---|---|
| 颜色不对 / 不好看 | accent、中性色 | "主色当前 `#1B365D`。改成 (a) 深一档 `#12233F`（更严肃）还是 (b) `#2B4A6F`（更友好）？" |
| 太花 | 是否违反单色规则 | "当前文档有 2 种强调色（蓝 `#1B365D` + 红 `#C8102E`）。违反单色规则。要 (a) 全换蓝 还是 (b) 全换红？" |
| 太单调 | 中性色层次 | "中性色现在只用了 2 级（正文色 + 辅助）。加 (a) 分割线用 `#87867f` 建立第 3 级 还是 (b) 卡片底用 `#faf9f5` 和画布区分？" |
| 太冷 | 是否误用冷灰 | "发现用了 `#999999`（冷灰）。换成暖灰 `#87867f` 吗？" |

### 3.3 字体 / 层级

| 用户说 | 先查 | 回问模板 |
|---|---|---|
| 字太小 | 正文 font-size | "正文当前 10.5pt。改成 (a) 11pt（更易读，但页数可能 +1）还是 (b) 11.5pt（舒服，页数肯定 +1）？" |
| 标题不突出 | H 字号跳跃 | "H2 现在 14pt，正文 10.5pt，跳跃 33%。加大到 (a) 16pt（跳跃 52%）还是 (b) 18pt（跳跃 71%，更戏剧）？" |
| 字体怪 | font-family 链 | "中文当前 `Source Han Serif SC`。换 (a) `Songti SC`（更传统）还是 (b) 保持现状但 weight 改到 400 轻一点？" |
| 看着不专业 | 文案 vs 排版 | "是 (a) 文案措辞（例：'致力于打造' 这种空话）还是 (b) 排版（对齐/字重/行高）？" |

### 3.4 禁忌响应

**绝对不要说的话**：

- ❌ "好的我来调整一下间距" → 必须说"间距是指 line-height 还是 padding？"
- ❌ "我加一些视觉元素" → 必须问"加 KPI 卡、图表、分割线，具体哪个？"
- ❌ "我让它更专业一点" → 必须问"更专业是指 (a) 文案还是 (b) 排版？"
- ❌ 未经确认就改 theme / 改字体链 / 改主色

### 3.5 连续反馈降级

如果用户连续 3 次说"还是不对"，停止调整，回问：

> "已经调了 3 轮还没 OK。能不能 (a) 发一张你觉得好看的参考图给我 还是 (b) 指一个网上的文档样例 URL？我现在盲改容易越走越偏。"
